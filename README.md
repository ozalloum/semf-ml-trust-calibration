# Paper  — SEMF/ML empirical reproducibility release

This public repository contains the reproducibility materials for the manuscript *When Should Machine Learning Trust the Semi-Empirical Mass Formula?*

## Contents

- `code/` — acquisition, validation, analysis, figure-generation, and audit scripts
- `data/` — processed analysis products and source AME files used by the locked pipeline
- `frozen_protocol/` — frozen protocol and implementation notes
- `results/` — locked development, confirmation, and stress-test outputs
- `tables/` — manuscript result tables
- `figures/` — main and supplementary figures in PDF, PNG, and SVG formats
- `audit/` — integrity and final empirical audit records
- `RELEASE_MANIFEST.json` and `RELEASE_STATUS.json` — release metadata

Raw AME data remain attributable to the Atomic Mass Evaluation publications and official distribution sites. See `RELEASE_READ_ME.md` and the protocol files for provenance and execution details.
